GOOGLE SHEETS SETUP
1. Create a Google Sheet.
2. Extensions -> Apps Script.
3. Paste google-apps-script.gs and save.
4. Deploy -> New deployment -> Web app.
5. Execute as: Me.
6. Who has access: Anyone.
7. Copy the /exec URL.
8. In script.js replace PASTE_YOUR_WEB_APP_URL_HERE with that URL.

The sheet stores timestamp, YES/NO, date type, selected date/time and her message.

The website intentionally avoids repeating the choices already shown on each page.
The NO button moves when the cursor gets close.
